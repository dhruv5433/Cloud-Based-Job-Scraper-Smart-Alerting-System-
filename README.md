# Cloud-Based-Job-Scraper-Smart-Alerting-System-
What it does:

Scrapes job portals daily (Selenium/BeautifulSoup)
Filters by skills, location, salary using ML matching
Sends personalized alerts via Email/WhatsApp
Cloud-hosted, runs 24/7 automatically

Subject fit:

Networks: HTTP requests, web protocols, API calls
Cloud: Deploy scraper on AWS/GCP, schedule with cron
Analytics: ML-based job-skill matching, trend analysis (which skills are in demand)
